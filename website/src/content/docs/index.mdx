## What this is

ContractsLibrary is an OpenZeppelin-style library for Cardano: complete
contracts shipped as an **on-chain validator**, **off-chain transaction
builders**, and a **formal specification**, so you can adopt a vetted
implementation instead of writing your own.

<CardGrid>
  <Card title="Use" icon="rocket">
    Supply parameters to a finished contract and ship. The off-chain builders
    assemble every transaction for you — no need to learn Aiken first.
  </Card>
  <Card title="Compose" icon="puzzle">
    Import the parameterized validation functions and helpers to build something
    new on top of a proven core.
  </Card>
  <Card title="Fork" icon="github">
    Copy the module and change it. The spec tells you exactly which behaviour
    you are changing, and the tests tell you if you broke it.
  </Card>
</CardGrid>
